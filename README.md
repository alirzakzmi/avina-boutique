# 🛍️ بوتیک آوینا | Avina Boutique

فروشگاه اینترنتی پوشاک و اکسسوری — ساخته‌شده با HTML، CSS و JavaScript خالص بدون فریم‌ورک و بدون بک‌اند.

## 🔗 لینک‌ها

- **🏠 فروشگاه:** [alirzakzmi.github.io/avina-boutique](https://alirzakzmi.github.io/avina-boutique/)
- **⚙️ پنل مدیریت:** [admin.html](https://alirzakzmi.github.io/avina-boutique/admin.html)

## ✨ امکانات

- صفحه اصلی با اسلایدر و فروش ویژه
- لیست محصولات با فیلتر (همه / تخفیف‌دار / ارزان‌ترین / گران‌ترین)
- صفحه جزئیات محصول با انتخاب سایز و رنگ
- سبد خرید با ذخیره‌سازی در `localStorage`
- ساید‌بار موبایل با منوی بازشو
- طراحی واکنش‌گرا (Responsive)

## ⚙️ پنل مدیریت

- **داشبورد:** آمار محصولات، تخفیف‌ها و میانگین قیمت
- **محصولات:** مشاهده، افزودن و حذف محصول
- سایر صفحات: پیام «در دسترس نیست»

## 📝 نکته

محصولات اضافه‌شده در پنل ادمین در `localStorage` مرورگر ذخیره می‌شوند — برای نسخه دمو کافی است، برای ادمین واقعی نیاز به بک‌اند و دیتابیس دارد.
